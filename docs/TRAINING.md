# 分阶段训练流程

## 1. 准备数据和模型

下载 Release 资源，检查 `reports/dataset_manifest.json`。基础集 40 条，扩充集 113 条，训练合计 153 条；另保留一个未见测试参考和一个早期辅助参考。转换输入与最终训练 CSV 在清单中单独分组，不混入训练采样。

处理过程包括关节顺序统一、根四元数统一为 xyzw、重采样至 50 Hz、关节限位与速度检查、按当前碰撞几何做根高度校正、地面和自碰撞检查。基础集保留 445704 帧；新增集保留 51634 帧。实际加载器生成的可评测控制转移数见评测文件，不能直接把文件帧数当成控制转移数。

训练碰撞模型保留 34 个碰撞体和显式质量/惯量，21 个关节均由策略控制。总质量 22.92451 kg。外观 Mesh 只用于独立渲染，不参与训练接触求解。模型核对记录见 `reports/model_fidelity.json`。

## 2. 第 0–500 轮：世界模型预训练

采样器以随机参考相位初始化物理环境，收集 `(state, action, context, next_state)` 到回放缓冲。状态为 55 维，动作 21 维，仿真参数 25 维。世界模型把根的绝对平面位置从输入中消去，使用 101 维输入预测 54 维状态增量。

使用 8 步窗口训练世界模型，累积多步预测误差。前 500 轮不做策略 BPTT；它们是第一阶段训练内部的预训练区间，无需另起一个任务。

## 3. 第 500–12000 轮：基础联合训练

每轮继续采集真实物理仿真数据并更新世界模型，然后固定世界模型参数，通过它展开 H=32 个想象控制步，对策略做 BPTT。固定参数仍允许梯度通过世界模型传播到动作和策略；下一轮世界模型继续更新。

价值网络通过回报目标训练，并为想象窗口外的未来回报提供 bootstrap。该算法不是 PPO；核心更新路径是 `collect → wm_update → policy_update/critic`。

默认：4096 个环境，世界模型批次 2048、每轮 10 批，策略批次 4096，世界模型宽度 2048×3、策略宽度 2048/1024/512/256、价值网络 256/128。控制 50 Hz，物理 500 Hz，AMP bf16。没有为了显存缩小网络、批次或想象窗口。

启动：`bash tools/train_lens110_lafan1.sh runs/my_stage1`。中断恢复：同一命令追加 `--resume`。

## 4. 第 12000–30000 轮：扩充联合训练

从第一阶段完整 `last.pt` 恢复世界模型、策略、价值网络、优化器和轮次。保留原 40 条动作的数值内容，新增 113 条，目标总轮次 30000，实际增加 18000 轮。

```bash
SUPERMIMICPLUS_STAGE1_RUN=runs/my_stage1 \
  bash tools/train_lens110_expanded.sh runs/my_stage2
```

程序要求显式开启“新运行目录”和“允许扩充动作库”，只放宽动作清单及其内容哈希，仍严格检查机器人、网络、关节、动作缩放和奖励契约。新目录记录恢复谱系，原目录保留。重启时重新采集回放缓冲，所以不是原进程逐比特延续。

## 5. 显存和物理容量

实际训练使用 `cudaMallocAsync`，EPA horizon 128，接触容量 128/环境，约束容量 512/环境，CCD 容量 64/环境。通过进程内后端适配器配置，保留物理模型几何。每个采集控制步检查溢出标记；发现溢出会停止。

RTX 5080 上约占用 15.3 GB 显存。硬件、驱动或依赖改变后，应重新执行启动容量检查。引擎对部分 cylinder-cylinder、cylinder-box 接触最多生成一个接触点，跨引擎行为需要另行验证。

## 6. 完整评测与模型选择

训练中的 `sim_rew` 平均所有并行环境当前步奖励；`ep_ret_norm` 统计当时结束的回合。最终比较应固定检查点，逐动作从首帧跑到结束，并分别报告硬终止、归一化回报、位姿误差和全局漂移。

30000 轮评测完成 153/153 动作，0 硬终止；平均回报 0.9014、按帧加权 0.8569，13 条动作回报低于 0.82。编号最大的检查点不必然在每个动作上最好，当前只确认已完成训练及该检查点的完整评测。
